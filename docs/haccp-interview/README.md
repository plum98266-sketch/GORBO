# HACCP 메일 인터뷰 키트

목표: 2주 안에 **컨설턴트 3명 이상 + 업체 사장님 5곳 이상**에게 메일로 답을 받아, "월 3만 원 휴대폰 HACCP 기록일지 앱"을 만들지 결정한다.

## 1. 진행 순서
| 날짜 | 할 일 |
|---|---|
| 1~2일차 | 연락처 30곳 모으기 (컨설턴트 10, 업체 20) → `tracker.csv`에 정리 |
| 3일차 | 첫 메일 발송 (하루 10통 이내, 한 통씩 이름 넣어서) |
| 7일차 | 답 없는 곳에 후속 메일 1번 (그 뒤로는 보내지 않음) |
| 7~12일차 | 답장 오면 감사 메일, 필요하면 추가 질문 1~2개 |
| 14일차 | 응답 정리 후 판단 (아래 5번 기준) |

응답률은 보통 10~20%입니다. 답장 8곳을 받으려면 40~60곳에 보내야 할 수 있습니다.

## 2. 연락처 찾는 곳
**컨설턴트 (먼저 연락. 응답률이 높고 업체도 소개해 줄 수 있음)**
- 네이버에서 "해썹 컨설팅", "소규모 HACCP 컨설팅" 검색 → 업체 홈페이지·블로그의 문의 메일
- 크몽·숨고의 HACCP 컨설팅 판매자 (플랫폼 메시지로 같은 내용 전송)
- 한국식품기술사협회, 지역 식품산업협회 회원사 공개 정보

**업체 사장님**
- [공공데이터포털 HACCP 인증업체 정보](https://www.data.go.kr/data/15028138/openapi.do)와 [식품안전나라](https://www.foodsafetykorea.go.kr)에서 지역·업종별 업체명 확인
- 업체 홈페이지, 스마트스토어 판매자 정보, 네이버 플레이스에 공개된 **사업용 메일**
- 컨설턴트에게 "고객사 2~3곳 소개"를 부탁하는 게 가장 효과적

## 3. 지켜야 할 것 (법·예의)
- 이 메일은 **광고가 아니라 의견을 묻는 인터뷰 요청**입니다. 판매·홍보 문구를 넣지 마세요. 영리 목적 광고성 메일은 사전 동의가 필요합니다(정보통신망법 제50조).
- 공개된 **사업용 메일**에만 보내고, 개인 메일을 찾아내서 보내지 않습니다.
- 메일마다 보내는 사람 이름과 연락처, 그리고 "원치 않으시면 답장 주시면 다시 연락드리지 않겠습니다" 문구를 넣습니다.
- 받는 사람을 **숨은참조(BCC)로 여러 명 묶어 보내지 말고**, 한 통씩 이름을 넣어 보냅니다. 스팸으로 분류되는 것도 막아줍니다.
- 후속 메일은 1번까지만 보냅니다.
- 답변 내용은 이름 없이 정리하고, 동의 없이 공개하지 않습니다.

## 4. 메일 템플릿
`{ }` 부분만 바꿔서 보내세요.

### A. 컨설턴트용 첫 메일
제목: `[의견 요청] 소규모 HACCP 업체 일지 작성 부담에 대해 여쭙고 싶습니다`

```
{컨설턴트 성함} 님, 안녕하세요.
{내 이름}이라고 합니다. 소규모 식품업체의 HACCP 기록 업무를 줄이는 도구를 준비하고 있어, 현장을 가장 잘 아시는 분께 의견을 여쭙고 싶어 연락드렸습니다.

판매나 홍보 목적이 아니며, 아래 질문 중 편하신 것만 짧게 답장 주셔도 큰 도움이 됩니다. (5분 정도면 됩니다)

1. 고객사(소규모 업체)들은 매일 일지를 주로 누가, 어떤 방식(종이/엑셀/기타)으로 작성하나요?
2. 사후관리 점검에서 지적받는 사항 중 '기록 관련'(누락, 몰아 쓰기, 개선조치 미기재 등)은 어느 정도 비중인가요?
3. 고객사가 일지 때문에 가장 힘들어하는 부분은 무엇인가요?
4. 휴대폰으로 일지를 쓰고(작성 시각 자동 기록, 작성 알림, 심사용 PDF 출력) 월 3~5만 원 정도라면, 고객사에 권하실 만할까요? 권하기 어렵다면 이유는 무엇일까요?
5. 혹시 이런 이야기를 나눠 볼 만한 고객사 사장님을 1~2곳 소개해 주실 수 있을까요? (어려우시면 괜찮습니다)

원치 않으시면 답장으로 알려주시면 다시 연락드리지 않겠습니다.

감사합니다.
{내 이름} 드림
{전화번호} / {메일 주소}
```

제목: `[의견 요청] HACCP 일지 작성, 어떻게 하고 계신지 여쭤봐도 될까요?`

```
{업체명} 대표님, 안녕하세요.
{내 이름}이라고 합니다. 매일 손으로 쓰시는 HACCP 일지를 조금이라도 덜 번거롭게 만드는 방법을 고민하고 있어, 현장에서 직접 하시는 분의 이야기를 듣고 싶어 연락드렸습니다.

판매 목적이 아니며, 편하신 질문만 한두 줄로 답장 주셔도 정말 큰 도움이 됩니다.

1. 매일 쓰시는 일지는 몇 종류쯤이고, 누가 언제 작성하시나요? (예: 하루 3번, 직원 1명)
```

## 5. 판단 기준 (14일차)
| 지표 | 계속 | 다시 생각 |
|---|---|---|
| 답장 수 | 8곳 이상 | 3곳 미만 |
| "월 3만 원이면 쓴다/권한다" | 답장의 60% 이상 | 30% 미만 |
| 기록 관련 지적 경험·몰아 쓰기 | 절반 이상이 "있다" | 거의 없다 |
| 컨설턴트의 고객사 소개 | 1명 이상 | 없음 |

- **계속**: 소개 페이지 + 사전 신청을 열고, 응답자에게 시제품 체험을 제안합니다.
- **다시 생각**: 거절 이유를 정리해서 2순위(외국인 근로자 기한 관리)로 넘어갑니다.
