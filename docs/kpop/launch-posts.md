## 시작 전에 꼭 할 것
1. **폼에 유입 경로 질문 추가**: 폼 편집 → 맨 아래 질문 추가 → 드롭다운
   - 질문: `Where did you hear about POB Map?`
   - 선택지: `Reddit` / `X (Twitter)` / `TikTok` / `A friend` / `Other`
   - 어느 채널이 효과 있는지 알아야 다음 2주를 어디에 쓸지 정할 수 있습니다.
2. **각 커뮤니티 규칙 먼저 읽기**: 대부분의 K-pop 서브레딧은 홍보 글을 금지하거나 주간 홍보 스레드에서만 허용합니다. 규칙을 어기면 계정이 차단됩니다.
3. **새 계정이면 1주일은 댓글로 활동**: Reddit은 갓 만든 계정의 링크 글을 스팸으로 자동 삭제하는 경우가 많습니다. 다른 사람 질문에 POB 정보를 답해 주며 활동 기록을 쌓으세요.

## 원칙
- **광고가 아니라 도움 글**로 씁니다. 링크는 마지막에 한 번만 넣거나, 허용되지 않으면 아예 빼고 댓글로 요청이 오면 답합니다.
- 공식 카드 이미지는 올리지 않습니다(저작권). 글과 표로만 정리합니다.
- 정보는 반드시 **매장 공지 원문으로 확인한 것만** 씁니다. 틀린 정보 한 번이면 신뢰를 잃습니다.
- 팬덤 용어 정리: POB(예약 특전), LD(lucky draw, 럭키드로우), PC(photocard), ver.(앨범 버전), KST(한국 시간), GO(group order, 공동구매), forwarder(배송대행).

### 글 A: 질문형 (홍보 금지인 곳에서도 대부분 가능, 링크 없음)
추천 위치: r/kpophelp 처럼 질문을 받는 서브레딧

**Title**
```
How do you keep track of which store has which POB for a comeback?
```

```

How do you all handle this?
- Do you use an app, a spreadsheet, or just follow certain accounts?
- What's the most annoying part for you (deadlines in KST, stores that don't ship abroad, info only posted in Korean)?

I can read Korean store notices, so I'm thinking of putting together English POB comparison tables for upcoming comebacks. Which groups would be most useful to cover?
```
